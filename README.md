# 🍽️ Janak Da Dhaba – Food Recipe App

**Janak Da Dhaba** is a sleek and responsive web application that allows users to explore a variety of food recipes. Built with modern web technologies, it offers a seamless user experience for food enthusiasts.

🔗 **Live Demo**: [janakdadhaba.vercel.app](https://janakdadhaba.vercel.app)

---

## ✨ Features

* 🔍 **Recipe Exploration**: Browse through a collection of delicious recipes.
* 🖥️ **Responsive Design**: Optimized for desktops, tablets, and mobile devices.
* ⚡ **Fast Performance**: Leveraging Vite for rapid development and loading times.
* 🎨 **Modern UI**: Styled with Tailwind CSS for a clean and intuitive interface.

---

## 🛠️ Tech Stack

* **Frontend**: [React.js](https://reactjs.org/)
* **Build Tool**: [Vite](https://vitejs.dev/)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:

* [Node.js](https://nodejs.org/) (v14 or later)
* npm or yarn

### Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/janakshukla/food_recipe.git
   cd food_recipe
   ```

2. **Install dependencies**:

   Using npm:

   ```bash
   npm install
   ```

   Or using yarn:

   ```bash
   yarn install
   ```

3. **Start the development server**:

   Using npm:

   ```bash
   npm run dev
   ```

   Or using yarn:

   ```bash
   yarn dev
   ```

   Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.
